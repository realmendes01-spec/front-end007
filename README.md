# Atividade: Google Maps em aplicações front-end

Mapa com marcadores personalizados dos centros de distribuição e traçado de rota (Directions API).

## Como usar
1. No Google Cloud Console, crie um projeto e habilite **Maps JavaScript API** e **Directions API**.
2. Gere uma chave de API e restrinja ao seu domínio.
3. Coloque a chave em `config.js`.
4. Abra `index.html` no navegador (ou publique com GitHub Pages).
